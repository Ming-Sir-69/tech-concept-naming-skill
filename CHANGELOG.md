# Changelog

User-facing changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [0.1.2] - 2026-10-17

### Added

- Essonym product name, selected plum logo, brand note and optional host icon metadata.

### Changed

- Present Essonym in both READMEs and the Skill heading. Installation ID, commands, state format and naming behavior remain unchanged.

## [0.1.1] - 2026-10-17

### Fixed

- Use project-wide Skill removal in the documented uninstall command: removing only one host after a multi-host install/update can retain the shared canonical directory. User-owned task state remains separate.

## [0.1.0] - 2026-10-17

### Added

- AI-led technical naming, concept exploration, source-aware etymology and independent Chinese localization.
- Optional local Python state helper with arbitrary candidate fragments, preferences, literal exclusions, revision checks and candidate statuses.
- Project-scoped Codex and Claude Code installation instructions, a refinement example, update/removal guidance and downloadable Skill package.

### Fixed

- A stored preference can be explicitly withdrawn without resetting other decisions.
- A candidate explanation can be refreshed after a fragment edit while retaining its history.
