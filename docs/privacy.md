# 数据与费用

Skill 是交给 AI 宿主读取的说明文件。本项目没有服务器、账户系统、数据库、后台遥测或付费 API。Python helper 使用标准库，只读写显式指定的本地状态；它不会联网或上传文件。

AI 宿主、模型和用户选择的检索工具独立运行。它们可能把产品描述、文件或候选发送给各自服务商；授权范围、数据政策、账户和费用由用户与服务商决定。“本仓库免费”不代表模型服务免费或离线。

helper 的 `naming.json` 可能包含未公开产品 brief、偏好、候选与修改历史。请存放在自己控制的工作区，公开反馈前脱敏；仓库已默认忽略名为 `naming.json` 的文件，其他自定义文件名需要自行排除。0600 文件权限不等于加密。

可选的 Vercel `skills` CLI 是外部安装器。本文档命令设置 `DISABLE_TELEMETRY=1`，按其官方说明关闭遥测及关联安全审计请求；GitHub/npm 下载仍会产生正常网络连接。不使用该工具时，可直接下载 ZIP 手工安装。

本仓库不附带第三方品牌素材或商业词典。MIT 只覆盖本仓库中按该许可提供的原创内容；不授予第三方商标、名称或外部资源的使用权。
